# Natal em Família — tela inicial de Natal para a TV box

Tela inicial leve para uma TV box Android 7 (RK322x): "Feliz Natal!", relógio, clima (Murici, AL),
neve caindo, moldura com as fotos da família (clique para expandir) e atalhos para YouCine e SmartTube.

- `NatalHome.apk`: o app. As fotos **não** ficam nele nem neste repositório.
- `src/`: o código (Java + página web em `app/assets/web`). A fonte Inter vem do
  [Free My TV](https://github.com/simbasjungles/free-my-tv) (`app/assets/fonts/InterVariable.ttf`, OFL).

As fotos ficam só na box, em `/sdcard/Android/data/io.natal.home/files/fotos/`: para trocar,
é só colocar ou tirar arquivos .jpg dessa pasta.
